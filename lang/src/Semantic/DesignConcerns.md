TokenType = std::string` is a performance issue.** Every token comparison (e.g., `tkn.type == TknType::LET`) is a heap-allocated string comparison. The standard approach is an `enum class TokenType { LET, FUNC, ... }`, which makes comparisons `O(1)` integer checks. The string-based approach also makes the `SINGLE_CHAR_TOKENS` and `KEYWORDS` lookup maps redundant with the type system.
